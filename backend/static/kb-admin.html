操作指引（备忘）
后台只做运营动作：发布 / 回滚 / 省份绑定 / 停用启用 / 查看。 建包、登记版本、改知识内容都在开发机脚本链路完成（构建成功用 build_release_index.py --register 自动登记，页面不再提供入口）。
更新贵州包：改 KB → rebuild_all.py（双轨期线上仍走 flat 索引，不跑则线上回答不变）→ split_knowledge_packs.py → build_release_index.py --register → Eval 通过 → 回这里发布。
新增省份：内容归类 → 扩展 split 脚本 → build_release_index.py --register --based-on <全国版本> → Eval → 回这里绑定 + 发布。
注意：Eval 未通过的版本发布会直接被拒；回滚只换版本指针、不删数据，可随时再切回； 保存省份绑定后该省账号下次提问立即生效；release 目录不可重建，构建失败换新 release-id。
完整流程与细节见 docs/knowledge-packs.md。
