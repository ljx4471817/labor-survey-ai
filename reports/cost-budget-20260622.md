## 六、档位 B：省级（700 人 / 7,000 次/月）⭐

### 6.1 配置

- **部署**：阿里云 ECS（2核4G 突发 t6）+ Cloudflare Tunnel named + 自有域名
- **域名备案**：政府单位走阿里云 ICP 备案系统（约 15-20 工作日，**免费**）
- **HTTPS**：Let's Encrypt 自动续期
- **不需要**：SLB（单机够用）、CDN（H5 体积小）、RDS（feedback.jsonl 暂存本地）
- **典型用户**：贵州省劳动力调查队、贵阳市调查队 + 各区县调查队

### 6.2 费用明细

| 开销项目 | 费用 |
|---------|------|
| LLM 输入（11.9M tokens） | ¥11.90 |
| LLM 输出（2.1M tokens） | ¥4.20 |
| Embedding（11.9M tokens） | ¥8.33 |
| ECS（2核4G t6） | ¥60 |
| .cn 域名（年付折月） | ¥2.5 |
| ICP 备案 | 一次性免费 |
| Cloudflare Tunnel named | 免费 |
| SSL 证书 | 免费 |
| **合计** | **≈ ¥87/月** |

### 6.3 风险

- **域名备案流程 15-20 工作日**：提前启动，**不能临到用时再备**
- **ECS 单点故障**：突发实例性能有限，**重要场景考虑升级到 c7（4核8G）月费 ¥300**
- **反馈数据存本地**：省级用户量大时建议上云数据库

### 6.4 高并发期表现

- 高并发期 7 天承担 60% 流量 = **每天 ~600 次**（按 8 小时工作日 ≈ 每分钟 1.25 次）
- 单 ECS 2核4G 跑 DeepSeek 转发**绰绰有余**（瓶颈在 DeepSeek 端 QPS 限额，不在本机）

### 6.5 采购建议

- **月度预算**：¥87/月 ≈ ¥1,044/年
- **一次性投入**：域名 ¥30 + 备案工时（无需费用）
- **可走采购流程**：政府采购协议供货，单价 < ¥100/月通常走小额采购或协议供货

## 九、关键风险与合规提示

### 9.1 数据合规（最高优先级）

- ❌ **居民个人信息禁止上云**：本系统当前架构（H5 不接触调查数据，仅返回 RAG 答案）已遵守
- ✅ 系统架构严格隔离：H5 → 后端 API → 阿里云百炼 / DeepSeek（仅传查询文本，不存个人数据）
- ⚠ 国家级档覆盖全国时，**采购合同中必须明确数据流向和隐私承诺**

### 9.2 政府采购流程

- 云资源按月租 ≥ 一定金额通常走**政府采购**或**协议供货**
- 域名备案：政府/事业单位域名必须备案，**流程约 15-20 工作日**
- API Key 管理：DeepSeek/DashScope 账号开在**单位名下**而非个人
- ¥87/月（省级档）属小额采购或协议供货范畴，**流程相对简单**

### 9.3 量纲校验

- ✅ 修正后三档人均月调用都 ≈ 10 次，**完全符合实际使用习惯**（处室每人每天不到 1 次，省级每人每周 2-3 次，国家级每人每周 2-3 次）
- 之前 v1 的 3×3 矩阵中异常档（如 100 人 × 20 万次 = 每人每天 67 次）已删除

### 9.4 技术演进路径

- **省级档向量库**：Chroma 嵌入式 + BM25 hybrid 当前够用，无需升级
- **国家级档向量库**：建议提前评估 Zvec（阿里通义实验室 2026-02 开源，详见项目 memory `zvec_alternative.md`）
- **稳定性增强**：省级档从 Cloudflare Tunnel quick 切 named tunnel（已规划）；国家级档考虑 SLB + 多 ECS 横向扩展
