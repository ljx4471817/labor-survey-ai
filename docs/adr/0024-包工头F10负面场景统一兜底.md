# 包工头 F10 负面场景统一兜底

## 背景

包工头就业判定采用总队口径（ADR 0023），但部分边缘场景仍可能引导系统输出 F10「否」的建议。这类建议容易和总队口径冲突，也不适合由系统自动给出。

## 决策

凡是包工头相关、原本可能建议 F10「否」的场景，一律不输出「否」建议，统一返回固定话术：

> 系统在学习中，请咨询业务负责人。

覆盖场景包括但不限于：明确不干、退休、转行，以及挂靠建筑公司并等待公司安排项目。固定话术通过 QA 的 `fixed_answer` 元数据在后端检索命中后直接返回，不再交由 LLM 改写。

## 后果

KB 429 仍用于自主承接、自负盈亏且存在业务活动的包工头场景；430、433、434 走固定话术。系统不自动判定这些负面场景的 F10/F11/F12。
