# ADR 0004：内网穿透方案

## 状态

已确认（2026-06-21）

## 背景

劳动力调查 AI 助手是处室自用工具，跑在用户本地电脑上。要让同事在手机/微信内能访问到 H5 页面，必须把 `localhost:8000` 暴露到公网。

需求约束：
- **免费**（处室自用，无运维预算）
- **运行期间稳定**（启动后不掉线、连接不频繁断开）
- **域名每次启动可变**（不需要固定域名，用完即关）
- 无需账号注册、不依赖自有域名

## 决策

**Cloudflare Tunnel · quick 模式**

启动命令：
```
cloudflared tunnel --url http://localhost:8000
```

启动后立即获得一个 `https://xxx.trycloudflare.com` 链接，由 Cloudflare 边缘节点维持隧道。运行期间稳定，重启后域名变化。

## 备选分析

### 备选 1：Cloudflare Tunnel quick（已采纳）
- ✅ 完全免费，无带宽/流量限制
- ✅ 无需账号、无需自有域名
- ✅ HTTPS 自带
- ✅ 启动后由 Cloudflare 边缘维持连接，掉线自动重连
- ⚠️ 每次启动域名变化（用户已接受）
- ⚠️ 国内访问 Cloudflare 偶尔抽风（多数情况可用）

### 备选 2：cpolar 免费版
- ✅ 二级域名固定，重启不换
- ✅ 国内访问速度快
- ❌ 免费版限速 1Mbps、月流量 1GB
- ❌ 语音 WebSocket 流量大，1GB 撑不了几天
- 评估：流量限制在处室规模下不可接受

### 备选 3：Cloudflare Tunnel named
- ✅ 域名永久固定
- ❌ 需要自有域名托管在 Cloudflare
- ❌ 配置成本高于 quick
- 评估：超出当前需求（用户接受域名可变）

### 备选 4：frp 自建
- ❌ 需要一台有公网 IP 的云服务器（年成本 ~300+）
- 评估：违反"免费"约束

### 备选 5：ngrok
- ❌ 国内访问经常被墙
- ❌ 免费版政策不稳定
- 评估：不推荐

### 备选 6：Tailscale / ZeroTier
- ❌ 访问方需要装客户端
- 评估：违反"扫码即用"原则

## 影响

- 部署脚本：`scripts/start_tunnel.bat` 一键启动后端 + tunnel
- 启动依赖：cloudflared 已通过 `winget install Cloudflare.cloudflared` 安装到系统
- 关闭依赖：关掉 cmd 窗口即停；不建议长时间无人值守运行
- 日志：cloudflared 输出到 stdout，URL 在启动后 ~5 秒内打印

## 风险

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| Cloudflare 国内访问慢/抽风 | 中 | 用户体验差 | 备用 cpolar；或换讯飞/腾讯云的代理 |
| cloudflared 进程意外退出 | 低 | 公网断联 | 写个简单的 watchdog 脚本（后续可加） |
| 公网链接泄露被滥用 | 低 | 资源消耗 | URL 不公开；只发给处室同事 |

## 部署步骤

1. 安装 cloudflared：`winget install --id Cloudflare.cloudflared --accept-package-agreements --accept-source-agreements`
2. 启动后端：进入 `backend/` 跑 `uvicorn app.main:app --port 8000`
3. 启动 tunnel：新开 cmd，跑 `cloudflared tunnel --url http://localhost:8000`
4. 把输出里的 `https://xxx.trycloudflare.com` 链接发给同事
5. 一键脚本：`scripts\start_tunnel.bat`（自动做 2+3）

## 回退方案

如果 Cloudflare Tunnel 不可用：
- **短期**：换 cpolar（注册即用，免费版的流量限制能接受的话）
- **中期**：自建 frp（需要云服务器，年成本 ~300）
- **长期**：买固定公网 IPv4 + DDNS（需运营商配合，已基本不可行）
