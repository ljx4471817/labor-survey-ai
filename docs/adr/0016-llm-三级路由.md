# ADR 0016：LLM 三级路由（MiniMax → qwen-flash → DeepSeek）

- 日期：2026-08-14
- 状态：已采纳

## 背景

MiniMax M2.7-highspeed（Token Plan 套餐）有 5h/7d 用量上限；DeepSeek 即将涨价；评测（reports/llm-cost-opt-20260814.md）显示 qwen-flash 在 104 条 eval 集上通过率 99% 持平生产基线（唯一差异为 temperature=0.3 非确定性波动，重跑通过），且按量价约为 MiniMax 的 1/15、无配额上限。

## 决策

LLM 路由从「MiniMax 主 / DeepSeek 备」两级扩展为三级优先链：

1. **MiniMax M2.7-highspeed（主）**：5h 用量 >=85% 或 7d >=90% 时切下一级。
2. **qwen-flash（DashScope，额度用尽后优先）**：按量付费无配额；用量回落（5h <70% 且 7d <85%）且冷却 >=30 分钟后切回 MiniMax。
3. **DeepSeek flash（deepseek-v4-flash，最后兜底）**：仅当 qwen-flash 不可用（fail-safe 沿链后移）或手动指定时使用；用量回落同样回主。

- 配额查询连续失败 3 次：fail-safe 沿链切下一级（minimax → dashscope → deepseek），不再直接跳 deepseek。
- 手动切换支持 minimax / dashscope / deepseek / auto。
- 配置：.env 中 `LLM_PROVIDER=minimax`（主模型不变）+ `DASHSCOPE_LLM_MODEL=qwen-flash`（复用 DASHSCOPE_API_KEY）。

## 影响

- 降低 MiniMax 套餐超限风险：额度用尽自动落到按量 qwen-flash，避免直接烧最贵的 DeepSeek。
- 成本：当前用量下 qwen-flash 月费约 ¥0.9（对比 MiniMax 按量约 ¥13.5）。
- 风险：qwen-flash 为外部按量服务，需保留 fail-safe 与手动切换；评测集 104 条覆盖有限，上线后观察使用监测差评。
- 相关代码：backend/app/services/llm_router.py、llm_switch_job.py、app/api/llm_admin.py、backend/static/dashboard.html。
