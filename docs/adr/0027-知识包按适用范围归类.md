# 知识包按适用范围归类

**状态：已采用（2026-10-19）**

知识包的归属由内容的业务适用范围决定，而不是由资料来源名称决定。QA/chunk 继续保留原始 `source` 作为来源出处；当某省第一版知识库已经采纳外省参考资料时，这些内容进入该省知识包，并在包 manifest 记录 `adopted_sources`，不为了归包而篡改来源，也不自动建立外省适用包。

## 考虑过的方案

- 把“四川题库”来源桶直接改名贵州包：会把来源出处错误表达成贵州资料，也与已有贵州包产生目录语义冲突，因此不采用。
- 立即支持一个省叠加多个知识包：只解决历史资料归类问题，却会提前引入索引、覆盖、版本、日志和回滚复杂度，因此不采用。
- 把所有参考内容直接提升为全国包：在尚未逐条业务复核前会扩大全国适用范围，因此暂不采用。

## 主要后果

- 当前只生成全国基础包与贵州包；QA 为全国 324 条、贵州 111 条。
- 四川题库来源的 32 条 QA 与 38 个 chunk 进入贵州包，`source` 原样保留。
- 贵州包 manifest 增加 `content_scope`、`adopted_sources` 和 `superseded_draft_packs`。
- 早期 `knowledge-base/packs/sichuan/` 来源桶草稿已被取代，并于 2026-10-19 经确认后删除。
