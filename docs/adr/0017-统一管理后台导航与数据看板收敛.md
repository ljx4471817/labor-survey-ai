# ADR 0017：统一管理后台导航与数据看板收敛

- 日期：2026-08-22
- 状态：已采纳

## 背景

dashboard / quiz-admin / whitelist / quiz-stats 四个管理页原先各自维护入口：dashboard 页内 tab-bar 同时出现「白名单管理」「测验管理」，与统一顶部导航重复；区县业务管理员登录落到 /dashboard 并自动内嵌白名单 iframe（?embed=1）。用户反馈「数据看板下不应出现白名单管理和测验管理」。

## 决策

1. **统一顶部导航**：dashboard / quiz-admin / whitelist / quiz-stats 共用 `common.js#initAdminNav` 渲染「数据看板 / 测验管理 / 白名单管理」（测验管理仅系统管理员/市级以上可见）。
2. **数据看板收敛**：dashboard 页内 tab-bar 只保留数据类 tab（KB 优化 / 使用监测 / 使用侧发现），移除「白名单管理」「测验管理」tab 及 iframe 内嵌模块（whitelistFrame / loadWhitelistModule 等死代码一并删除）。
3. **登录路由调整**：区县业务管理员登录直落 `/whitelist-admin` 独立页（替代 ADR 0015 中「区县 → /dashboard 白名单模块」的落点）；进入数据看板默认显示「使用监测」。
4. **移除 embed 兼容**：whitelist.html 删除 `?embed=1` 隐藏页头/页脚分支，白名单页仅以独立页形态存在。

## 影响

- 信息架构更清晰：数据看板 = 看数据，白名单/测验 = 管理功能，各自独立页 + 统一导航。
- 区县业务管理员日常白名单维护一步直达。
- 删除 dashboard 内嵌 iframe 与 whitelist embed 分支，减少死代码。
- 相关代码：backend/static/dashboard.html、whitelist.html、login.html、common.js。
- 修订关系：本 ADR 覆盖 ADR 0015 中「区县业务管理员登录落点」与「白名单内嵌模块」部分。
