# 腾讯云轻量应用服务器部署指南

> 迁移目标：从「本地 + Cloudflare Tunnel」迁移到「腾讯云轻量服务器 + 域名」
> 生成日期：2026-07-27
> 状态：备案已通过，域名可直接用；本地 rsync 同步（含 .env 和数据文件）

---

## 阶段 0：控制台配置（5 分钟）

1. 登录腾讯云 → 轻量应用服务器 → 拿到**公网 IP**、登录用户名（ubuntu 或 lighthouse）、密码
2. 进入「防火墙」→「添加规则」，开放：
   - 22 SSH
   - 80 HTTP
   - 443 HTTPS
   - 8001 不要开放（后端不直接暴露）
3. SSH 登录：ssh ubuntu@<公网IP>

---

## 阶段 1：系统初始化

`ash
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv git nginx curl
sudo timedatectl set-timezone Asia/Shanghai
sudo ln -sf /c/Users/Administrator/AppData/Local/Microsoft/WindowsApps/python3 /usr/local/bin/python
`

---

## 阶段 2：本地 rsync 同步代码 + 数据 + .env

> 因为 .env 和 data/ 都没在 GitHub 上，直接从本地同步最方便

在**本地项目根目录**执行：

`ash
rsync -avz \
  --exclude='.git' --exclude='venv' --exclude='__pycache__' \
  --exclude='backend/data/chroma' \
  ./ ubuntu@<公网IP>:/opt/labor-survey-ai/
`

> backend/data/chroma 排除掉，因为索引会在服务器上 rebuild，比传过去快

同步完之后登录服务器确认：

`ash
ssh ubuntu@<公网IP>
ls /opt/labor-survey-ai/.env              # 应该有
ls /opt/labor-survey-ai/backend/data/     # 应该看到 whitelist.db 等
`

---

## 阶段 3：检查 .env 配置

`ash
cd /opt/labor-survey-ai
cat .env
`

确认以下关键项已填好：

- DASHSCOPE_API_KEY
- DEEPSEEK_API_KEY
- LSX_AUTH_SECRET（如果之前没填，生成一个：python -c "import secrets; print(secrets.token_hex(32))"）
- CHROMA_DIR=/opt/labor-survey-ai/backend/data/chroma

## 阶段 5：构建知识库（Chroma + BM25）

在服务器上执行，这一步会调 DashScope embedding API，需要联网：

`ash
cd /opt/labor-survey-ai
source backend/venv/bin/activate
python scripts/rebuild_all.py
`

跑完检查：

`ash
python -c "
import chromadb
c = chromadb.PersistentClient(path='backend/data/chroma')
col = c.get_collection('labor_survey_qa')
print(f'Chroma 条目数: {col.count()}')

## 阶段 6：本地验证

`ash
cd /opt/labor-survey-ai/backend
source venv/bin/activate
uvicorn app.main:app --host 127.0.0.1 --port 8001
`

另开一个 SSH 窗口验证：

`ash
curl -s http://127.0.0.1:8001/health | python -m json.tool
`

看到 {"status":"ok","chroma_count":xxx} 就对了。Ctrl+C 停掉临时进程。

## 阶段 7：systemd 守护（开机自启）

`ash
sudo nano /etc/systemd/system/labor-survey.service
`

粘贴：

`
[Unit]
Description=Labor Survey AI Backend
After=network.target

[Service]
Type=simple
User=ubuntu
Group=ubuntu
WorkingDirectory=/opt/labor-survey-ai/backend
Environment=PATH=/opt/labor-survey-ai/backend/venv/bin:/usr/local/bin:/usr/bin:/bin
ExecStart=/opt/labor-survey-ai/backend/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8001
Restart=always
RestartSec=3
EnvironmentFile=/opt/labor-survey-ai/.env

[Install]
WantedBy=multi-user.target
`

启用并启动：

`ash
sudo systemctl daemon-reload
sudo systemctl enable labor-survey
sudo systemctl start labor-survey
sudo systemctl status labor-survey
`

## 阶段 8：Nginx 反向代理 + 域名 + HTTPS

### 8.1 写 Nginx 配置

`ash
sudo nano /etc/nginx/sites-available/labor-survey
`

粘贴（把 your.domain.com 换成真实域名）：

`
ginx
server {
    listen 80;
    server_name your.domain.com;
    return 301 https://System.Management.Automation.Internal.Host.InternalHost;
}

server {
    listen 443 ssl;
    server_name your.domain.com;

    ssl_certificate /etc/letsencrypt/live/your.domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your.domain.com/privkey.pem;

    client_max_body_size 10M;

    location / {
        proxy_pass http://127.0.0.1:8001;
        proxy_set_header Host System.Management.Automation.Internal.Host.InternalHost;
        proxy_set_header X-Real-IP ;
        proxy_set_header X-Forwarded-For ;
        proxy_set_header X-Forwarded-Proto ;
    }
}
`

### 8.2 启用 Nginx 配置

`ash
sudo ln -sf /etc/nginx/sites-available/labor-survey /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
`

### 8.3 申请 Let's Encrypt 证书

`ash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your.domain.com
`

certbot 会自动改 Nginx 配置实现 80→443 跳转 + 自动续期。
