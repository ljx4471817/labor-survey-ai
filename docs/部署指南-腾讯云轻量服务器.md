## 部署步骤（已验证）

### 阶段 0：控制台配置
- 开放防火墙：22、80、443（8001 不开放）
- 重置密码 → **必须重启实例**才生效

### 阶段 1：系统初始化
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv git nginx curl
sudo timedatectl set-timezone Asia/Shanghai
sudo ln -sf $(which python3) /usr/local/bin/python
sudo reboot
```

### 阶段 2：代码同步
```bash
cd /opt
sudo git clone https://github.com/ljx4471817/labor-survey-ai.git
sudo chown -R ubuntu:ubuntu /opt/labor-survey-ai
```

### 阶段 3：传输 .env 和 data/
```powershell
# 本地 PowerShell 执行
scp D:\code_codex\labor-survey-ai\.env ubuntu@129.211.27.85:/opt/labor-survey-ai/.env
scp -r D:\code_codex\labor-survey-ai\backend\data ubuntu@129.211.27.85:/opt/labor-survey-ai/backend/
```
> ⚠️ data/ 整个目录传（含 chroma），比 rebuild 快

### 阶段 4：安装依赖
```bash
cd /opt/labor-survey-ai/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# requirements 已含 python-multipart（上传）与 openpyxl（完成率导出 Excel），无需再手动装
# （可选）支持 .doc/.wps 导入转换：sudo apt install -y libreoffice-writer
```

### 阶段 5：本地验证
```bash
uvicorn app.main:app --host 127.0.0.1 --port 8001
# 另开窗口
curl -s http://127.0.0.1:8001/health | python3 -m json.tool
# 应返回 {"status":"ok","chroma_count":497,...}
```

### 阶段 6：systemd 守护
```bash
sudo nano /etc/systemd/system/labor-survey.service
```
```ini
[Unit]
Description=Labor Survey AI Backend
After=network.target

[Service]
Type=simple
User=ubuntu
Group=ubuntu
WorkingDirectory=/opt/labor-survey-ai/backend
Environment=PATH=/opt/labor-survey-ai/backend/venv/bin:/usr/local/bin:/usr/bin:/bin
ExecStart=/opt/labor-survey-ai/backend/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8001
Restart=always
RestartSec=3
EnvironmentFile=/opt/labor-survey-ai/.env

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl daemon-reload
sudo systemctl enable labor-survey
sudo systemctl start labor-survey
```

### 阶段 7：Nginx + HTTPS
```bash
# 先写纯 HTTP 配置
sudo tee /etc/nginx/sites-available/labor-survey > /dev/null << 'EOF'
server {
    listen 80;
    server_name laborforceai.xyz;
    client_max_body_size 10M;
    location / {
        proxy_pass http://127.0.0.1:8001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF
sudo ln -sf /etc/nginx/sites-available/labor-survey /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx

# 再申请证书（certbot 会自动改配置加 HTTPS）
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d laborforceai.xyz
```

## 踩坑记录

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| DEEPSEEK_API_KEY 为空也能在本地跑 | 本地系统环境变量已设置 | 服务器上必须写在 .env 里 |
| uvicorn 启动报 python-multipart 缺失 | CSV 上传功能需要 | `pip install python-multipart` |
| nginx -t 报证书文件不存在 | 配置里引用了还没申请的证书 | 先纯 HTTP 配置，再跑 certbot |
| nginx 配置报 unknown directive GNU | 粘贴带入特殊字符 | 用 `tee` 命令重写文件 |
| 完成率导出报缺 openpyxl | 新功能依赖 | `pip install openpyxl`（已入 requirements） |
| .doc/.wps 导入提示无法解析 | Linux 无 Word/WPS | `sudo apt install -y libreoffice-writer` 后即可转换；或转存 .docx |
| 测验异步任务 404/失败 | uvicorn 多 worker（进程内存任务表） | **保持单 worker**（指南 systemd 即单进程，勿加 --workers） |

## 日常更新代码

**本地（改完代码后）：**
```bash
git add -A && git commit -m "xxx" && git push origin main
```

**服务器（两行）：**
```bash
cd /opt/labor-survey-ai && git pull && sudo systemctl restart labor-survey
```

**如果改了知识库（faq.json / markdown）：**
```bash
cd /opt/labor-survey-ai && source backend/venv/bin/activate && python scripts/rebuild_all.py --incremental
```
