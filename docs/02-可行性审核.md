## 二、技术可行性：高

### 2.1 各模块评价

| 模块 | 方案 | 评价 |
|------|------|------|
| 前端 | 微信小程序原生 | 合适。无需安装、扫码即用，符合基层场景 |
| 后端 | Python FastAPI | 合适。RAG 生态成熟、异步性能好 |
| 向量库 | Chroma → Milvus | 合适。MVP 阶段 Chroma 即可，500 条 QA 完全够用 |
| 大模型 | DeepSeek | 合适（中文强、成本低）。但方案中写的"V4"需要核实——目前 DeepSeek 公开模型是 V3 系列（V3.0/V3.1/V3.2） |
| Embedding | BAAI/bge-large-zh-v1.5 | 合适。但若本地部署会占 2C4G 服务器约 1.3GB 显存且 CPU 推理慢，**已决策改走 API**（智源 BGE API 或 DashScope text-embedding-v3） |
| ASR | 腾讯云 / 讯飞（**2026-06-21 已停用**，输入法自带） | 合适。入户场景需注意背景噪音，方言识别需要测试 |
| 离线 FAQ | jieba.js + TF-IDF | 可行。但 jieba 字典约 3-5MB，需放**分包**避免撑爆 2MB 主包 |

### 2.2 技术细节修正建议

1. **DeepSeek 型号**：方案写 "DeepSeek V4"，核实当前可用模型（注册 API 时确认）
2. **流式输出**：`wx.request` 的 `enableChunkedTransfer` 仅基础库 2.20.1+ 支持，覆盖率约 95%。**主推 WebSocket**，chunked 作为降级
3. **Embedding API 选型**：BGE API（智源开放平台）vs DashScope（阿里）均可，后者配套 Qwen 系列，国内服务稳定
4. **离线分包**：jieba 字典 + FAQ JSON 必须放**分包**加载，避免撑爆 2MB 主包

## 三、时间估算可行性：中

### 3.1 方案估算：6-10 周

### 3.2 风险点

方案说 6-10 周，但有几个被低估的点：

- **Phase 1（知识库整理）实际是最大瓶颈**：500 条 QA 的收集、校对、标准化、标注来源，单人做可能要 4-6 周（取决于文档可获得性）
- **Phase 4 备案 2-4 周是并行项**，不能计入主线时间
- **小程序基础库兼容调试**会消耗 1-2 周（特别是流式输出、语音录音、离线缓存这几块）
- **单人非全职情况**：实际可能 10-14 周才能到 MVP 体验版可用

### 3.3 应对

**分迭代交付**，每 2 周一个可演示版本，避免一次性拖到 10 周才发现方向有问题：

- 迭代 1（2 周）：知识库 50 条 + 后端 RAG + 小程序文字输入整段返回
- 迭代 2（2 周）：知识库扩到 200 条 + 流式输出 + 知识来源标注
- 迭代 3（2 周）：语音输入 + 离线 FAQ + 网络状态自动切换
- 迭代 4（2-4 周）：知识库到 500 条 + 处室测试 + 性能优化

## 五、合规可行性：中 ⚠️⚠️

### 5.1 这是项目最大的不确定性

- **个人主体小程序**：可以做"体验版"绑定自己微信号使用，**但仅限个人/小范围测试**
- **用于公务场景**：严格来说应当用**单位主体**（国家统计局贵阳调查队）正式备案
- **数据隐私**：用户问题会上传云端（DeepSeek API），需考虑：
  - 是否记录用户查询日志
  - 是否涉及居民个人信息（应当避免让小程序接触居民数据）
- **AI 合规**：《生成式人工智能服务管理暂行办法》——内部工具不面向公众，压力较小，但方案文档如果对外公开需注意

**红线问题必须在动手前确认**——即使技术上能跑起来，如果单位主体备案不下来，整个项目的扩展目标（贵州全省、全国推广）会落空。

### 5.2 已决策的合规路径

**两阶段路径**：

**阶段 A（个人主体验证期，0-3 个月）**
- 注册个人微信小程序，做"体验版"——绑定你和处室同事微信号即可使用
- 用户范围严格控制在处室内（不超过 10-20 人）
- 服务部署在个人腾讯云账号下
- **数据约束**：不在小程序里收集居民个人信息；用户问题日志保留不超过 30 天
- 验证目标：产品价值被处室同事认可、形成使用习惯

**阶段 B（切单位主体，3 个月后启动）**
- 与贵阳调查队沟通，正式备案单位主体小程序
- 服务迁移到单位账户（如单位有云资源）或继续使用个人云但签订协议
- 用户范围扩展到贵阳市调查队系统
- 完成 ICP 备案（单位主体，约 2-4 周）

**过渡触发条件**（满足任一即启动）：
1. 处室使用频次稳定且希望扩展到其他处室
2. 单位主动要求接手
3. 个人主体小程序触及个人使用上限
