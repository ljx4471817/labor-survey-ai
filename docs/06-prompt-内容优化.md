# 任务 A1：复杂场景案例（50-100 条）

针对调查员入户时遇到的边界情况、特殊人群、模糊场景，给出明确判断。重点覆盖：

1. **季节性就业**：农忙/渔民/牧民/护林员/季节性餐馆
2. **多份工作并行**：白天上班 + 晚上兼职、白领 + 自媒体
3. **跨地区/远程办公**：外出打工人员、远程办公、跨境务工
4. **退休返聘**：领取养老金但仍工作、退休人员兼职
5. **劳务派遣 vs 直接雇佣**：派遣工怎么算、合同主体
6. **家庭经营 vs 个体经营**：家庭农场、夫妻店、个体工商户
7. **季节性歇业**：餐馆冬季歇业、店铺装修期间
8. **新就业形态**：网约车、外卖骑手、直播带货、平台接单、自由撰稿
9. **特殊人群**：服刑人员、军人、宗教人士、长期病假
10. **过渡状态**：刚入职/刚离职、试用期、待岗、培训期

每条用真实案例形式：包含具体身份、行业、问题点、判断依据。

# 任务 A2：询问/沟通技巧（30-50 条）

调查员入户时**怎么问**比"问什么"更重要。覆盖：

1. **老人沟通**：听不懂术语时怎么办（"找工作"对老人的含义）
2. **敏感问题询问**：收入、家庭关系、年龄、婚姻状况
3. **代答处理**：户主代答 vs 本人回答、未成年人代答、邻居代答
4. **模糊回答追问**："差不多"、"一般"、"有时候"怎么追问出准确信息
5. **入户开场白**：自我介绍、建立信任、《致调查户的一封信》使用
6. **拒访应对**：住户不开门、不配合、怕泄露隐私
7. **中途退出**：问到一半住户要赶人
8. **多人同住**：家庭多名成员在场时如何分别询问
9. **PAD 操作技巧**：现场录入注意事项、网络不好的应对
10. **回访技巧**：第一次未访到，二次入户的话术

每条包含：场景 → 问题点 → 推荐话术 → 注意事项。
